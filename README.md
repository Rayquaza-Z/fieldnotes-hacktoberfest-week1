# 🌿 Fieldnotes

**The offline voice-first nature journal. Speak outside — it tells you what you
just saw. No internet. No account. No cloud. No compromises.**

## What this is

Fieldnotes identifies birds, plants, and insects from a spoken description and
logs every sighting to a GPS-tagged journal. The entire pipeline — speech
recognition, reasoning, species grounding — runs on your own machine. Take it
into the field with zero bars and it works exactly the same.

## Why it's built different

- **Fully offline by design.** faster-whisper transcribes on-device, a local
  open-weight model (Gemma via Ollama) reasons on-device. Nothing you say or see
  ever leaves your computer.
- **Grounded, not guessing.** The model only ever sees a 6–8 species shortlist
  and must answer in JSON. Ids outside the shortlist are dropped and flagged as
  `grounding_violation`. Flat confidences are replaced with rank-based scores and
  marked. The follow-up question is generated by code, not hallucinated.
- **A real installable app, zero dependencies.** The browser UI is an offline
  PWA (manifest + service worker) served by pure-stdlib Python — including app
  icons encoded pixel-by-pixel with no image library. Add it to your home
  screen and it behaves like a native field app.
- **It knows where you are.** GPS-tagged entries, offline region detection, and
  a UI that reconfigures itself for mobile field mode vs laptop.
- **Yours to extend.** Swap models with one env var, add a whole region with
  one JSON file.

## How it works

```
voice ──▶ faster-whisper (base.en, on-device) ──▶ transcript
                                                   │
typed text ────────────────────────────────────────┘
                                                   ▼
                        keyword shortlist (6–8 species, local data)
                          only transcript + shortlist reach the model
                                                   ▼
                        local LLM ──▶ top 3, confidence-sorted, grounding-checked
                                                   ▼
                        code-written follow-up ("Does it have: …?")
                                                   ▼
                        you tap the right one ──▶ journal.json (+ GPS, device, latency)
```

## Use it (no terminal needed)

1. One-time setup below (plus `ollama serve` running).
2. Double-click **`start-fieldnotes.bat`** and **keep its window open** — that
   window *is* the app server.
3. Tap the microphone and speak, or expand *"or describe it in words"* to type.
4. Tap the right species — or *None of these*. Logged.

On a phone, **Add to Home Screen** for the full-screen field app. If the page
ever shows a red *Server unreachable* banner, the server window was closed —
re-run the bat file and hit Retry. The mic requires `http://127.0.0.1:8765`
(or HTTPS); browsers block microphones anywhere else.

## Build it yourself

```bat
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install faster-whisper sounddevice numpy ollama
ollama serve
ollama pull gemma3:1b

.\.venv\Scripts\python.exe app.py              & :: UI at http://127.0.0.1:8765
.\.venv\Scripts\python.exe fieldnotes.py listen --region gujarat
.\.venv\Scripts\python.exe fieldnotes.py text "green parrot with red beak" --region gujarat
.\.venv\Scripts\python.exe fieldnotes.py stats
.\.venv\Scripts\python.exe -m unittest -v       & :: 15 tests
```

`--region` (default `gujarat`, `FIELDNOTES_REGION` fallback),
`FIELDNOTES_MODEL` (default `gemma3:1b`). Unknown regions exit listing what's
available. `stats` reports top-1 / top-3 / shortlist-coverage hit rates plus
grounding violations.

## Share a live link

This can't go on Vercel-style hosting — it needs a long-running Python process
and local models, not serverless functions. To show anyone, expose your running
machine with one command:

```bat
cloudflared tunnel --url http://127.0.0.1:8765
```

That prints a public `https://…` URL (mic works — it's HTTPS).

## Project layout

```
fieldnotes.py             CLI + scoring, grounding, confidence, follow-up, journal (220 lines)
app.py                    stdlib-only web UI: voice upload, PWA, PNG icons, GPS, device modes
start-fieldnotes.bat      double-click launcher (keep its window open)
data/species_gujarat.json 50 Surat-area birds, plants, insects (4–6 field marks each)
test_fieldnotes.py        15 unittest tests: scoring, grounding, regions, follow-up, confidence, ranking
docs/                     screenshots + demo GIF
journal.json              your sightings (created on first save; git-ignored)
```
